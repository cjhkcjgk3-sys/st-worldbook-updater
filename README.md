# 世界书更新器

在酒馆里并排浏览两本世界书，把母本中选中的条目复制或替换到目标书。电脑和手机都保留左右双栏；条目窗和正文窗上下分开、各自可调高度。点选条目后正文会自动在下方展开。无需模型 API、酒馆助手或额外服务器。

## 安装与升级

面向 SillyTavern 1.18.0 及更新版本；接口已核对 1.18.0、1.19.0 官方源码，用户实际安装环境仍需试用验证。

### 通过酒馆直接安装

在酒馆“扩展 → 安装扩展”中粘贴下方仓库链接，完成后刷新网页：

```text
https://github.com/cjhkcjgk3-sys/st-worldbook-updater.git
```

后续可以在酒馆的扩展管理中检查更新。

### 手动安装或覆盖

1. 解压安装包，找到 `st-worldbook-updater` 文件夹。
2. 将整个文件夹放进运行酒馆的设备上的 `SillyTavern/data/default-user/extensions/`。多用户环境把 `default-user` 换成对应账号目录。
3. 确认文件位于 `SillyTavern/data/default-user/extensions/st-worldbook-updater/manifest.json`，避免多套一层目录。
4. 刷新酒馆网页，在扩展设置中点击“打开世界书更新器”。

已安装旧版本时，覆盖同名扩展文件夹后刷新即可；扩展 ID 保持不变。

手机浏览器访问电脑或服务器上的酒馆时，扩展也安装在电脑或服务器。酒馆的“安装扩展”输入框用于 Git 仓库链接；本 ZIP 使用解压安装方式。

## 核心操作

「母本」提供条目和设置，默认在左，可以选择酒馆已有的世界书，也可以打开酒馆原生世界书 JSON 文件。「目标书」接收更新，默认在右。

想把母本放右边时，打开「配对操作」并点击「交换左右」。条目列表和正文对照一起换边，当前选书、搜索、配对和勾选都会保留。同一浏览器下次打开时会沿用上次的位置。

名单为空时，可在底部手动复制或替换勾选的条目：

| 操作 | 已配对且勾选的条目 | 其他母本条目 |
| --- | --- | --- |
| 替换 · 仅正文 | 替换已配对且有变化的条目正文，保留目标设置 | 不复制未配对条目 |
| 替换 · 完整条目 | 同步母本提供的标题、关键词、正文和设置 | 不复制未配对条目 |
| 复制所选 | 完整复制母本当前搜索结果里已勾选的条目 | 允许复制重复项，每次都会创建新副本 |

默认替换范围是“仅正文”。完整替换保留目标编号、列表位置和母本未提供的扩展字段。复制会分配新的本地编号、追加到列表末尾并保留完整设置。

目标书独有及未勾选的条目保留，目标书名称、绑定和顶层元数据保留。插件不自动删除条目。写入用于后续生成请求，已有聊天消息保持原样。

## 定点名单

在顶部「定点名单」填写目标书应收录的人名，每行一个。点底部「按名单更新」，预览会逐项列出替换、复制、无变化、待核对和母本未找到的人名。确认后一次写入目标书。

目标书已有条目时，按底部「替换范围」更新，有相同内容时自动跳过。目标书缺少的人物从母本复制完整条目。已选中的空世界书也可以作为目标。名单外条目保留，搜索、分页和手动勾选只影响列表或手动操作。

| 写法 | 效果 |
| --- | --- |
| `爱芮` | 与条目名精确匹配 |
| `维琳娜·艾嘉德` | 忽略全／半角、标点、空格与间隔号 |
| `零号·安比（安比·德玛拉）` | 括号里的英文名、曾用名也参与匹配 |
| `雷电将军=雷神` | 一行写多个叫法，任一命中即可 |
| `拉菲` | 也会找到 `拉菲（改造）` 这类形态。匹配出多条时列为待核对 |
| `丽莎` / `丽莎·敏兹` / `原神·丽莎` | 带间隔号的中文全名可按首段简称匹配。原神及 Genshin 前缀自动识别 |
| `琴` / `琴·古恩希尔德` | 支持单字首段简称。有多个候选时预览会列为待核对 |
| `哥伦比娅` / `哥伦比亚` | 支持这组译名异写，也能匹配带间隔号的全名 |
| `菲谢尔` → `菲谢尔，奥兹` | 合写的目标条目按第一个名字配对。预览显示实际条目名，确认后更新整条 |
| `作品别名：作品甲=别称` | 为其他作品补充可识别的前缀 |

名单比对条目名、首段简称、别名和主关键词。`安比` 不会因名字后半段相同而命中 `零号·安比`。用了简称且任一侧匹配出多个候选时，预览会列为待核对。目标书存在同名候选时，可手动配对后重新预览。

开启「匹配置顶（仅显示）」后，两侧列表里**已配对**或**名单命中**的条目会一起排到最前，块内顺序跟随母本：母本第 1、3、6、7 位的四个角色，置顶后在列表里就是第 1、2、3、4 位，其余条目保持原相对顺序。

这是**显示层的排序**：不写回世界书、不改 `displayIndex`、不动正文和注入顺序。清空定点名单或断开匹配，列表立刻恢复原顺序。

「复制母本条目名」把母本的条目名按行复制出来（自动去掉分类前缀与楼层元数据）。可以交给外部 AI 挑出某部作品的人物，再把结果粘回名单；插件本身不调用 AI。含分隔符的完整条目名可使用 JSON 字符串格式，例如 `"Alice,Bob"`，以免被拆成两个名字。

标题旁边显示当前版本号，方便确认装的是不是最新版。

## 条目设置（批量）

母本里的条目设置可以批量修改，再按配对同步到目标书。面板位于窗口顶部的「条目设置」工具中，默认收起；复选框选中的母本条目可直接作为批量设置范围。

支持的核心设置：

| 设置 | 说明 |
| --- | --- |
| 注入位置 | 角色前 / 角色后 / 作者注上 / 作者注下 / 指定深度 / 示例上 / 示例下 |
| 深度、插入角色 | 仅在“指定深度”时生效 |
| 注入顺序 | 数字越小越先注入 |
| 常驻（蓝灯） | 开=蓝灯常驻，关=绿灯关键词触发；会清除向量化状态，启用/禁用另算 |
| 不可递归、防止进一步递归、延迟到递归、无视回复限额 | 四个递归开关 |

填写方式：字段选「设为」或「调整」（数字字段可以写 +2、-3），没选的字段不会提交。「作用范围」可选当前条目、当前勾选的母本条目、定点名单命中或母本全部条目。

两个按钮都要确认后才写入：**应用到母本**、**同步设置到目标书**（按配对关系把母本的实际设置覆盖到目标书）。设置、列表置顶和同步目标书是独立操作；标题、关键词、正文一律不动。

## 勾选与配对

所有复选框使用同一套选择。母本与目标书的条目配对后，两边的复选框同步；默认勾选需要替换的配对条目。目标书独有条目无法勾选。列表上方只有一个切换按钮，可对母本当前搜索结果跨页全选或取消全选。

两个清单默认每页显示 25 条，可分别改为 10、50、100、500 或 1000 条。翻页不会清空勾选。复制处理当前搜索结果里已勾选的条目；搜索隐藏的勾选留在原处，不会被复制。替换和批量设置可以处理被搜索隐藏但已勾选的条目，并会在确认时说明。

| 入口 | 可用操作 |
| --- | --- |
| 顶部「配对操作」 | 「配对所选／解除配对」智能复用按钮、重新匹配、重置配对、全部解除、交换左右 |
| 顶部「定点名单」 | 限定替换范围、查看命中报告、复制母本条目名 |
| 顶部「条目设置」 | 按当前条目、已勾选、名单或整本批量设置 |
| 底部 | 有名单时使用「按名单更新」；名单为空时可手动复制或替换。替换可选仅正文或完整条目 |

自动配对依据条目名和主关键词，优先使用唯一且证据较强的候选，正文和次要关键词不参与判断；缺少主关键词时可使用唯一名称。重名仍可能是不同人物，请核对结果。手动配对或解除后重新自动匹配及重新载入会尽量保留有效的人工决定；如需放弃这些决定，可使用重置操作。切换世界书会清除当前决定，并在有人工操作时先请求确认。

未配对、待核对或重复的母本条目都可以复制。要替换未配对条目，先在顶部配对工具中手动配对。复制已配对的母本条目时只会创建新副本，不会替换原配对目标。执行前确认窗口列出目标和条数，取消不会写入。

## 界面与手机操作

窗口沿用酒馆主题色、弹窗、按钮、输入框和全局滚动条。电脑和手机都使用双栏列表。条目窗与正文窗上下排列，中间有明显的硬分隔；两个窗体底部各有触屏/鼠标拖拽手柄，可独立上下拉高（最高 2400px，在工作区内独立滚动，不压扁另一侧）；正文对照顶部另提供一个循环切换按钮（「高度：均分／正文大／列表大」，点击也可一键复位手动高度）和「收起」按钮。两窗内的左右栏各自硬分隔，长列表和正文独立滚动。

点任一条目后，正文对照自动在下方展开。配对项不在对侧当前页时，列表会自动定位到对应页。顶部三个工具面板按需展开，一次显示一个，再点面板标题或点击面板外任意区域即可收起；顶栏右上角直接提供「重新载入」「放大／还原」和「关闭窗口」三个按钮。

手动配对或解除时，分别点选两侧条目，再在顶部「配对操作」点「配对所选」（已配对时同一按钮自动切换为「解除配对」）。新的人工配对会解除冲突配对；配对后核对正文和勾选状态。

## 支持范围

- 一次处理一组世界书，条目总数最多 10000；本地 JSON 文件上限 20 MB。
- 接受酒馆原生世界书 JSON：`entries` 为对象，条目正文为字符串；不接收角色卡、条目数组或压缩包。
- 正则关键词按文本比较，正文按纯文本显示；预览不执行 HTML、脚本、宏或模板。
- 删除、直接编辑及条目拆分合并继续使用酒馆原生编辑器。
- 浏览器需支持原生对话框。写入前请先保存原生编辑器的更改，并将原生世界书编辑器切换到其他书或取消选择；要写入的世界书正被原生编辑器选中时插件会拒绝写入。
- 插件写入不会主动取消其他世界书的宿主延迟保存，并会回读核验；酒馆未提供完整的同书事务锁或跨标签版本检查。操作时避免其他标签页、插件或外部程序同时修改相关世界书，重要数据请先备份。
- `examples` 提供「演示_母本.json」和「演示_目标书.json」，可用于试用复制和替换。

## 源码与验证

运行代码无额外依赖。扩展入口是 `index.js`；`core.js` 负责配对、定点名单匹配、替换和完整条目写入，`host.js` 负责酒馆读写核验，`ui.js` 与 `style.css` 负责界面。

数据与异常测试：

```sh
npm test
```

测试覆盖配对、名单、替换、融合、手动选择、条目设置和保存保护；具体数量以运行结果为准。

浏览器测试另需开发环境安装 Playwright 与 Chromium：

```sh
node tests/browser-smoke.mjs
```

浏览器测试使用本地模拟酒馆接口。检查记录见 `VERIFICATION.md`，续接状态见 `NEXT.md`，当前范围见 `PLAN.txt`。
