# 世界书更新器

在酒馆里并排浏览两本世界书，批量更新或融合到左侧原书。两侧条目列表固定左右并列，点选任一条目后正文会自动在下方展开，方便对照。支持电脑和手机，无需模型 API、酒馆助手或额外服务器。

## 安装与升级

面向 SillyTavern 1.18.0 及更新版本；接口已核对 1.18.0、1.19.0 官方源码，用户实际安装环境仍需试用验证。

### 通过酒馆直接安装

在酒馆“扩展 → 安装扩展”中粘贴下方仓库链接，完成后刷新网页：

```text
https://github.com/cjhkcjgk3-sys/st-worldbook-updater.git
```

后续可以在酒馆的扩展管理中检查更新。

### 手动安装或覆盖

1. 解压安装包，找到 `st-worldbook-updater` 文件夹。
2. 将整个文件夹放进运行酒馆的设备上的 `SillyTavern/data/default-user/extensions/`。多用户环境把 `default-user` 换成对应账号目录。
3. 确认文件位于 `SillyTavern/data/default-user/extensions/st-worldbook-updater/manifest.json`，避免多套一层目录。
4. 刷新酒馆网页，在扩展设置中点击“打开世界书更新器”。

已安装旧版本时，覆盖同名扩展文件夹后刷新即可；扩展 ID 保持不变。

手机浏览器访问电脑或服务器上的酒馆时，扩展也安装在电脑或服务器。酒馆的“安装扩展”输入框用于 Git 仓库链接；本 ZIP 使用解压安装方式。

## 核心操作

左侧选原世界书；右侧选已有世界书，或直接打开酒馆原生世界书 JSON 文件。

在原有下拉框选择操作，共用一个执行按钮：

| 选项 | 已配对且勾选的条目 | 右侧勾选的新条目 |
| --- | --- | --- |
| 更新 · 仅正文 | 仅替换正文 | 不追加 |
| 更新 · 完整条目 | 同步新版明确提供的标题、关键词和运行设置 | 不追加 |
| 融合 · 仅正文 | 仅替换正文 | 追加完整新条目 |
| 融合 · 完整条目 | 同步新版明确提供的标题、关键词和运行设置 | 追加完整新条目 |

默认是“更新 · 仅正文”。完整更新保留目标编号、列表位置和来源未提供的扩展字段；插入顺序等运行设置仍按新版更新。新增条目分配新的本地编号，排到列表末尾，保留完整设置。

左侧独有及未勾选的条目保留，原书名称、绑定和顶层元数据保留。普通融合会跳过完整重复项；手工复制则是明确创建副本，重复操作会再次新增。插件不自动删除条目。写入用于后续生成请求，已有聊天消息保持原样。

## 定点名单

按角色名只处理指定的人物，适合把一本“全家桶”世界书分发回各个作品的书里：名单外的人物既不替换，也不复制。

底部「定点名单」每行一个名字；留空则整本参与，行为与之前一致。

| 写法 | 效果 |
| --- | --- |
| `爱芮` | 与条目名精确匹配 |
| `维琳娜·艾嘉德` | 忽略全／半角、标点、空格与间隔号 |
| `零号·安比（安比·德玛拉）` | 括号里的英文名、曾用名也参与匹配 |
| `雷电将军=雷神` | 一行写多个叫法，任一命中即可 |
| `拉菲` | 自动带上 `拉菲（改造）` 这类形态条目 |
| `作品别名：原神=Genshin` | 名单里带作品名时先去掉再比较 |

名单比对条目名和主关键词，不使用正文或次要关键词，也不做包含或模糊匹配：`安比` 不会命中 `零号·安比`，`小安比` 不会命中 `安比`。面板列出未找到的名字。名单用于定位条目，不是身份保证；同名或主关键词重叠时请核对置顶结果并按需取消勾选或手动配对。

开启「匹配置顶（仅显示）」后，两侧列表里**已配对**或**名单命中**的条目会一起排到最前，块内顺序跟随母本：母本第 1、3、6、7 位的四个角色，置顶后在列表里就是第 1、2、3、4 位，其余条目保持原相对顺序。

这是**显示层的排序**：不写回世界书、不改 `displayIndex`、不动正文和注入顺序。清空定点名单或断开匹配，列表立刻恢复原顺序。

「复制来源条目名」把右侧来源书的条目名按行复制出来（自动去掉分类前缀与楼层元数据）。可以交给外部 AI 挑出某部作品的人物，再把结果粘回名单；插件本身不调用 AI。含分隔符的完整条目名可使用 JSON 字符串格式，例如 `"Alice,Bob"`，以免被拆成两个名字。

填写名单后默认切换到融合：名单命中的已配对条目可以更新，未配对条目可以新增，两者能在一次执行中完成。核对配对和勾选后，选择仅正文或完整条目再执行。

标题旁边显示当前版本号，方便确认装的是不是最新版。

## 条目设置（批量）

母本里的条目设置可以批量改好，再同步到目标书，不用再去那本书逐条改。面板折叠在底部，默认收起。

支持的核心设置：

| 设置 | 说明 |
| --- | --- |
| 注入位置 | 角色前 / 角色后 / 作者注上 / 作者注下 / 指定深度 / 示例上 / 示例下 |
| 深度、插入角色 | 仅在“指定深度”时生效 |
| 注入顺序 | 数字越小越先注入 |
| 常驻（蓝灯） | 开=蓝灯常驻，关=绿灯关键词触发；会清除向量化状态，启用/禁用另算 |
| 不可递归、防止进一步递归、延迟到递归、无视回复限额 | 四个递归开关 |

填写方式：字段选「设为」或「调整」（数字字段可以写 +2、-3），没选的字段不会提交。「作用范围」可选当前条目、母本设置模式下勾选的条目、定点名单命中或母本全部条目。

两个按钮都要确认后才写入：**应用到母本**、**同步设置到目标书**（按配对关系把母本的实际设置覆盖到目标书）。设置、列表置顶和同步目标书是独立操作；标题、关键词、正文一律不动。

## 勾选与配对

常用批量操作集中在菜单中，避免增加一排按钮。

| 入口 | 可用操作 |
| --- | --- |
| 勾选模式与操作 | 切换更新/融合勾选、手工复制勾选、母本设置勾选，并提供批量全选和取消 |
| 配对操作 | 配对所选、解除所选配对、解除全部配对、重新自动匹配，以及重置人工决定 |
| 正文对照 | 点选条目后，下方显示两侧正文和关键词；条目区与正文区可分别调整高度 |

三种勾选模式互不干扰。更新/融合模式的批量选择作用于当前名单范围，包括被搜索隐藏的可执行项。手工复制和母本设置模式的全选只选右侧当前可见项；可跨搜索累积勾选，全部取消会清空该模式的勾选。手工复制只执行当前可见且已勾选的条目，搜索隐藏的勾选保留但本次不复制。勾选决定操作对象，点击条目决定查看或手动配对对象。

自动配对依据条目名和主关键词，优先使用唯一且证据较强的候选，正文和次要关键词不参与判断；缺少主关键词时可使用唯一名称。重名仍可能是不同人物，请核对结果。手动配对或解除后重新自动匹配及重新载入会尽量保留有效的人工决定；如需放弃这些决定，可使用重置操作。切换世界书会清除当前决定，并在有人工操作时先请求确认。

待处理项可手动标记新增；名单范围内的待处理项也可以勾选后参与融合，应先核对。手工复制可复制已配对、待处理或完全重复的来源条目，并会创建新副本；重复执行会再次创建。执行前确认窗口列出操作数量，取消不会写入。

## 界面与手机操作

窗口沿用酒馆主题色、弹窗、按钮和输入框样式。电脑与手机都保留原书在左、新版在右的双栏列表；不会在手机上切成单侧标签。点任一条目后，窗口下方自动展开原书/新版正文并排区，不用再找「查看正文」按钮。选中已配对条目时，另一侧会同步定位到对应条目。

窗口右下角有浏览器自带的缩放柄。条目区和正文区各有独立的拖动条及高度输入框，拖动或输入像素值可单独调整，不会挤压另一区域；每个区域最大高度为首次打开时弹窗高度的 50 倍。键盘可在拖动条上使用上下方向键微调，Home/End 调到边界。整个弹窗内容可向下滚动，列表和正文较长时仍可在各自区域内滚动。顶栏右上角的展开图标可放大或还原整个窗口，更多菜单可重新载入或关闭窗口。

手机屏幕较窄时，左右两列仍同时显示；定点名单、配对与条目操作折叠收纳，短屏时可从顶栏更多菜单展开。更新方式、已选数量和主操作位于窗口内容底部，可向下滚动到达。短横屏与搜索键盘弹出时会压缩次要控件，为列表留出空间。

手动配对时，分别点选左右条目，再展开「配对与条目操作」选择「配对所选」。新的人工配对优先于冲突的旧配对；配对后请核对正文和勾选状态。

## 支持范围

- 一次处理一组世界书，融合后的总条目数最多 10000；本地 JSON 文件上限 20 MB。
- 接受酒馆原生世界书 JSON：`entries` 为对象，条目正文为字符串；不接收角色卡、条目数组或压缩包。
- 正则关键词按文本比较，正文按纯文本显示；预览不执行 HTML、脚本、宏或模板。
- 删除、直接编辑及条目拆分合并继续使用酒馆原生编辑器。
- 浏览器需支持原生对话框。写入前请先保存原生编辑器的更改，并将原生世界书编辑器切换到其他书或取消选择；目标书正被原生编辑器选中时插件会拒绝写入。
- 插件写入不会主动取消其他世界书的宿主延迟保存，并会回读核验；酒馆未提供完整的同书事务锁或跨标签版本检查。操作时避免其他标签页、插件或外部程序同时修改相关世界书，重要数据请先备份。
- `examples` 提供演示旧版和新版，可用于试用更新、融合与恢复。

## 源码与验证

运行代码无额外依赖。扩展入口是 `index.js`；`core.js` 负责配对、定点名单匹配、替换与融合，`host.js` 负责酒馆读写核验，`ui.js` 与 `style.css` 负责界面。

数据与异常测试：

```sh
npm test
```

测试覆盖配对、名单、替换、融合、手动选择、条目设置和保存保护；具体数量以运行结果为准。

浏览器测试另需开发环境安装 Playwright 与 Chromium：

```sh
node tests/browser-smoke.mjs
```

浏览器测试使用本地模拟酒馆接口。检查记录见 `VERIFICATION.md`，续接状态见 `NEXT.md`，当前范围见 `PLAN.txt`。
