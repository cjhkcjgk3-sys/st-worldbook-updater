# 世界书更新器 v1.1

在酒馆里用双窗口对照两本世界书，批量更新或融合到左侧原书。支持电脑和手机，无需模型 API、酒馆助手或额外服务器。

## 安装与升级

面向 SillyTavern 1.18.0 及更新版本；接口已核对 1.18.0、1.19.0 官方源码，用户实际安装环境仍需试用验证。

### 通过酒馆直接安装

在酒馆“扩展 → 安装扩展”中粘贴下方仓库链接，完成后刷新网页：

```text
https://github.com/cjhkcjgk3-sys/st-worldbook-updater.git
```

后续可以在酒馆的扩展管理中检查更新。

### 手动安装或覆盖

1. 解压安装包，找到 `st-worldbook-updater` 文件夹。
2. 将整个文件夹放进运行酒馆的设备上的 `SillyTavern/data/default-user/extensions/`。多用户环境把 `default-user` 换成对应账号目录。
3. 确认文件位于 `SillyTavern/data/default-user/extensions/st-worldbook-updater/manifest.json`，避免多套一层目录。
4. 刷新酒馆网页，在扩展设置中点击“打开世界书更新器”。

已安装 v1.0 时，覆盖同名扩展文件夹后刷新即可。扩展 ID、账号作用域和备份存储格式保持不变，原有本地备份继续按原方式读取。

手机浏览器访问电脑或服务器上的酒馆时，扩展也安装在电脑或服务器。酒馆的“安装扩展”输入框用于 Git 仓库链接；本 ZIP 使用解压安装方式。

## 核心操作

左侧选原世界书；右侧选已有世界书，或直接打开酒馆原生世界书 JSON 文件。

在原有下拉框选择操作，共用一个执行按钮：

| 选项 | 已配对且勾选的条目 | 右侧勾选的新条目 |
| --- | --- | --- |
| 更新 · 仅正文 | 仅替换正文 | 不追加 |
| 更新 · 完整条目 | 同步新版明确提供的标题、关键词和运行设置 | 不追加 |
| 融合 · 仅正文 | 仅替换正文 | 追加完整新条目 |
| 融合 · 完整条目 | 同步新版明确提供的标题、关键词和运行设置 | 追加完整新条目 |

默认是“更新 · 仅正文”。完整更新保留目标编号、列表位置和来源未提供的扩展字段；插入顺序等运行设置仍按新版更新。新增条目分配新的本地编号，排到列表末尾，保留完整设置。

左侧独有及未勾选的条目保留，原书名称、绑定和顶层元数据保留。相同条目跳过；插件不自动删除条目。写入用于后续生成请求，已有聊天消息保持原样。

## 勾选与配对

常用批量操作集中在菜单中，避免增加一排按钮。

| 入口 | 可用操作 |
| --- | --- |
| 勾选操作 | 全部勾选、全部取消；融合模式另有“仅勾选更新”“仅勾选新增” |
| 配对操作 | 配对所选、解除所选配对、解除全部配对、重新自动匹配 |
| 配对操作中的新增标记 | 融合时可将待处理条目标记为新增，或取消新增标记 |
| 查看正文 | 使用同一个查看入口，对照两侧条目，也支持只看单侧条目 |
| 备份与恢复 | 原有折叠入口中下载备份或整书恢复 |

批量勾选对整组世界书生效，包括搜索隐藏的可执行项；搜索时会明确提示这一范围。全部取消可以直接清空部分勾选，不需要先全选。已配对条目的左右复选框同步。

勾选与点击条目是两件事：勾选决定写入哪些内容，点击决定当前查看或手动配对的对象。

插件结合标题和完整主关键词自动配对。唯一、无冲突且有变化的配对默认勾选。“新条目”在融合模式下可勾选追加；重名、共享或部分重叠关键词等歧义项显示“待处理”，不会被批量全选自动追加。确认确实属于独立新条目时，选中右侧条目，在配对操作中标记为新增。完全重复的条目跳过。

切换更新/融合或正文/完整范围会保留已有勾选意图。重新载入、重新自动匹配或切换两边世界书会重建配对与默认勾选。执行前确认窗口会列出目标书、更新数量和新增数量；取消确认不会写入或覆盖备份。

## 手机使用

条目列表固定左右各半，分别搜索、滚动。正文对照在竖屏自动上下各半，横屏与电脑左右各半；返回列表保留浏览位置。搜索键盘压缩可视区域时，界面会收起次要操作，保留列表与底部主操作。

## 备份与中断

每次写入前保存目标书的完整备份；更新和新增在内存中一起准备，然后一次提交保存，并从服务器重新读取核验。

每本书保留最近一次操作前副本，按酒馆账号隔离，保存在当前浏览器。“备份与恢复”中可以下载原生 JSON，或恢复整本书。融合后的恢复会一并撤销该次更新和新增；已有后续修改时，恢复前会提示覆盖影响。

清除网站数据、更换浏览器或设备后，本地备份不会自动跟随。需要长期保留时使用“下载备份”。

备份失败时不写入。预览后原书被修改，会停止操作并提示重新载入。保存结果未确认时，保留备份并阻止连续重复提交；刷新整个酒馆网页，再选择原书核验结果。

提示编辑器与服务器尚未同步时，先等待酒馆自动保存；仍有提示则刷新酒馆后重新载入。

## 支持范围

- 一次处理一组世界书，融合后的总条目数最多 10000；本地 JSON 文件上限 20 MB。
- 接受酒馆原生世界书 JSON：`entries` 为对象，条目正文为字符串；不接收角色卡、条目数组或压缩包。
- 正则关键词按文本比较，正文按纯文本显示；预览不执行 HTML、脚本、宏或模板。
- 删除、直接编辑及条目拆分合并继续使用酒馆原生编辑器。
- 浏览器需支持原生对话框与 IndexedDB；备份存储不可用时阻止写入。
- `examples` 提供演示旧版和新版，可用于试用更新、融合与恢复。

## 源码与验证

运行代码无额外依赖。扩展入口是 `index.js`；`core.js` 负责配对、替换与融合，`host.js` 负责酒馆读写核验，`storage.js` 负责备份，`ui.js` 与 `style.css` 负责界面。

数据与异常测试：

```sh
npm test
```

浏览器测试另需开发环境安装 Playwright 与 Chromium：

```sh
node tests/browser-smoke.mjs
```

浏览器测试使用本地模拟酒馆接口。检查记录见 `VERIFICATION.md`，续接状态见 `NEXT.md`，当前范围见 `PLAN.txt`。
