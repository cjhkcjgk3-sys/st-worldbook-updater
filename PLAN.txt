世界书更新器｜项目规划 v1.5

一、目标与范围

在 SillyTavern 里并排浏览母本和目标书，手动核对条目，再把母本的内容复制或替换到目标书。电脑和手机使用双栏布局，默认母本在左、目标书在右。

只处理一组世界书；原生世界书读写、保存和回读核验沿用酒馆接口。母本也可以是酒馆原生 JSON 文件。

二、操作闭环

选择母本和目标书 → 填写目标书应收录的角色名 → 预览替换、复制、无变化和待核对条目 → 确认后一次写入并回读核验。已选的目标书可以为空。

勾选母本条目后可用「同步所选」一次预览替换、新增和人工决定；「复制所选」「替换所选」也可直接处理全部勾选。

三、界面与批量操作

弹窗沿用酒馆 `.popup`、`.menu_button`、`.text_pole`、主题变量及全局滚动条。条目与正文同步换边，可在「配对操作」中交换左右，浏览器记住上次的位置。每侧有选书、搜索、列表、条数和分页；默认每页 25 条，另可选 10、50、100、500、1000。DOM 只渲染当前页，选择状态跨页保留。

两个清单列使用酒馆的 `wi-card-entry` 外观，中间有清楚的竖向分隔。点击条目后在下方自动展开正文对照；母本与目标书的正文各自滚动。条目窗与正文窗之间使用明显的横向硬分隔，两个窗体分别用触屏／鼠标拖拽手柄调高低。弹窗顶栏图标用于放大/还原窗口。

复选框只表达“选中了哪些母本条目”。已配对时，左右复选框同步。初始勾选需要替换的已配对条目；未配对的母本条目默认不勾选。列表上方可按已配对、待核对或可新增分别批量勾选和取消，覆盖母本当前搜索结果的所有分页。

「同步所选」在有无名单时均处理所有勾选的母本条目：自动匹配的默认替换，明确缺失的默认新增，待核对的由用户选替换目标或新增。预览逐项允许修改操作，解决所有待决定项后一次写入。
「复制所选」将勾选条目作为新副本，允许相同内容；「替换所选」要求为每条指定替换目标。两者均可在预览中调整。搜索隐藏与其他分页的勾选也参与。

“配对操作”“定点名单”“条目设置”在窗口上方工具区按需展开，一次展开一个。配对操作包括手动配对、解除所选、解除全部、重新自动匹配和重置人工决定。定点名单用于批量更新，也可作为条目设置的范围。条目设置可对母本应用字段，也可按配对同步到目标书。

四、配对与复制规则

根据条目名和主关键词自动配对，只有唯一且无冲突的候选才配对；正文和次要关键词不参与身份判断。目标书独有内容保留。无配对母本条目可以直接勾选复制，也可先手动配对后替换。

复制会分配不冲突的原生编号，完整保留母本条目配置并追加到目标书末尾。普通同步默认跳过完全相同的新增内容；明确选择「复制新副本」时可以重复创建。

五、选择与失败处理

点选条目只影响正文查看和手动配对；复选框决定写入对象。选中状态跨页保留。批量勾选仅针对母本当前搜索结果中的对应类别，复制、替换和同步都包含搜索隐藏的已选项；条目设置按其选择范围处理。

空列表、搜索无结果和无可替换项需分别提示。确认取消不写入。更换母本、目标书或重置配对时，提示将清除的临时配对与勾选。

操作前核对目标。目标书已变化、删除或改名时停止写入。保存后重新从服务器读取并核验；结果不明确时阻止盲目重试。写入前保存短期临时备份，也可先在酒馆导出重要数据。

六、技术与边界

原生 JavaScript 模块、少量 CSS 和标准 manifest.json；不引入 React、酒馆助手、额外服务器或模型 API。扩展 ID 与设置命名保持兼容。

总条目最多 10000；本地 JSON 文件最多 20 MB。预览按纯文本展示，不执行 HTML、脚本、宏或模板。条目删除、直接编辑及复杂修改继续使用酒馆原生编辑器。

七、验证与续接

数据测试关注自动/人工配对、内容替换、复制编号、条目设置和保存失败保护。浏览器检查关注双栏、分页、搜索、跨页选择、自动正文对照、两窗缩放、手机触摸和宿主保存核验。

当前代码版本、已执行检查和待实机验收项以 `NEXT.md` 与 `VERIFICATION.md` 为准。真实 SillyTavern 与真实手机验收单独记录。
